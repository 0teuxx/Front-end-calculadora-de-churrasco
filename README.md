# 🍖 Calculadora de Churrasco - Full Stack

> **ATUALIZANDO - SENDO APRIMORADO COM O TEMPO**

Esta é uma aplicação web desenvolvida para automatizar o cálculo de insumos necessários para um churrasco. O sistema calcula quantidades de carnes, acompanhamentos e bebidas com base no perfil dos convidados (homens, mulheres e crianças).

---

## 🎓 Formação Acadêmica
Este projeto foi desenvolvido como resultado prático do curso de **Python** realizado no **SENAI de Jandira**, concluído em **Outubro de 2025**. O objetivo foi aplicar conceitos de lógica de programação, manipulação de dados e desenvolvimento web com Flask.

---

## 🚀 Tecnologias Utilizadas

* **Python**: Back-end e lógica de cálculo.
* **Flask**: Framework web para criação das rotas e servidor.
* **HTML5 & CSS3**: Interface do usuário e estilização.
* **Git & GitHub**: Controle de versão e hospedagem.

---

## 🛠️ Como acessar e rodar o projeto

Para visualizar a calculadora funcionando no seu computador, siga os passos:

1.  **Pré-requisitos:** Tenha o Python instalado.
2.  **Baixe o código:** ```bash
    git clone [https://github.com/0teuxx/Front-end-calculadora-de-churrasco.git](https://github.com/0teuxx/Front-end-calculadora-de-churrasco.git)
    cd Front-end-calculadora-de-churrasco
    ```
3.  **Instale o Flask:**
    ```bash
    pip install flask
    ```
4.  **Inicie o servidor:**
    ```bash
    python app.py
    ```
5.  **Acesse a página:** No seu navegador, digite: `http://127.0.0.1:5000`

## 📝 Funcionalidades
- Separação de consumo por gênero e idade.
- Cálculo automático de carnes bovinas, suínas e frango.
- Estimativa de bebidas e carvão necessária.
- Design Simples(por enquanto) porém responsivo.
